Release Changelog

v2.0.1 Patch

View on GitHub ↗

Released: August 2026

  • Enhancement: Modernized JMeter JMX export with dynamic variable resolution and smart URL parsing.
  • Performance: Overhauled Collection Runner multi-threading queue to use bounded ExecutorService (CallerRunsPolicy) fixing massive memory leaks.
  • Performance: Implemented real-time streaming of request metrics to temporary disk files, keeping Runner memory footprint flat on millions of iterations.
  • Performance: Added UI log truncation (max 2000 rows) to keep the Results Table lightning fast.
  • New: Added "Runner Queue Multiplier" in Global Settings to tune background queue capacity.
