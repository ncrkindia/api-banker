Introduction

Welcome to the comprehensive ApiBanker User Guide. This manual is designed to take you from a beginner to an advanced power user. ApiBanker is built natively on GraalVM to ensure millisecond startup times while offering robust safety paradigms for critical workflows.

Workspace Setup

When you launch ApiBanker, you are greeted with the animated splash screen and then dropped into your default Workspace.

  • Creating Collections: Group related API requests into Collections for better organization. Right-click the sidebar to create a new Collection.
  • Workspace Portability: Workspaces are saved as local JSON files, making them easily version-controlled via Git.

Environment Manager

The Environment Manager acts as the central hub for defining environment-specific data like Base URLs, API keys, and staging endpoints. This avoids hardcoding sensitive or fluid values in your requests.

  • Switching Contexts: Use the dropdown in the top navigation bar to seamlessly switch between Development, Staging, and Production environments.
  • Scope Hierarchy: Environment variables take precedence over Collection variables, which in turn override Global variables.

Global & Local Variables

Variables allow for dynamic data injection during request execution.

Define variables using the mustache syntax: {{variable_name}} within your URLs, headers, or body data.

Recursive Resolution

ApiBanker features deep recursive variable resolution. If a Collection variable resolves to an Environment variable, the UI and the centralized script engine will evaluate it completely. Hover over any variable in the UI to see its deeply resolved value via a tooltip.

Managing Requests

Configuring requests is fluid thanks to the auto-managing table model.

  • Params & Headers: The UI automatically appends empty rows dynamically as you type. Empty rows that lose focus are automatically pruned to reduce UI clutter.
  • Request Cancellation: If a request is hanging or taking too long, the "Send" button turns into a "Cancel" button, allowing you to safely abort the thread mid-flight.
  • Double-Click Protection: Built-in debounce mechanisms prevent accidental duplicate requests from being fired simultaneously.

Authentication

ApiBanker supports various auth types out of the box:

  • Bearer Token: Automatically configures the Authorization: Bearer <token> header. Supports variable resolution.
  • Basic Auth: Safely encodes your username and password into a Base64 authorization header.
  • OAuth 2.0: Configure token endpoints, client IDs, and secrets to fetch and refresh tokens dynamically.

Scripting & Tests

ApiBanker allows you to run custom JavaScript code before a request is sent (Pre-request Script) and after a response is received (Tests). This is perfect for dynamically setting variables, hashing payloads, or asserting response data.

1. Pre-Request Script Examples

Use pre-request scripts to generate timestamps, calculate hashes, or dynamically assign variables before the payload is sent.


// Set a global variable with the current timestamp
apibanker.globals.set("current_time", new Date().toISOString());

// Calculate a hash and set it as an environment variable
const payloadHash = btoa("my_secret_payload");
apibanker.environment.set("auth_hash", payloadHash);

2. Test Script: Validating Response Status

Assert that the server responds with a success code.


apibanker.test("Status code is 200", function () {
    apibanker.response.to.have.status(200);
});

apibanker.test("Response is reasonably fast", function () {
    apibanker.expect(apibanker.response.responseTime).to.be.below(500); // 500ms
});

3. Test Script: Validating JSON Body

Parse the JSON response and assert specific object properties exist and are correct.


apibanker.test("User object is valid", function () {
    var jsonData = apibanker.response.json();
    
    // Check if fields exist
    apibanker.expect(jsonData).to.have.property("id");
    apibanker.expect(jsonData).to.have.property("email");
    
    // Assert value
    apibanker.expect(jsonData.status).to.eql("active");
});

4. Using Different Variables in Scripts

You can interact with different variable scopes dynamically based on your testing needs:


// Fetch a value from the Environment scope
var apiKey = apibanker.environment.get("api_key");

// Fetch a value from the Collection scope
var defaultTimeout = apibanker.collectionVariables.get("timeout");

// Extract a token from response and save it Globally
var jsonData = apibanker.response.json();
apibanker.globals.set("session_token", jsonData.token);

SSL Validation

Ensure your connections are secure. During introspection, ApiBanker automatically validates the SSL certificate of the target endpoint.

Hover over the security padlock icon next to your URL bar to view color-coded, bolded feedback regarding the SSL validation status, certificate expiration, and issuer details.

OpenAPI Imports

ApiBanker fully supports OpenAPI 3.2 specs.

Navigate to File > Import to select an OpenAPI JSON or YAML file. ApiBanker will reconstruct the entire API tree as a Collection, generating all endpoints, query parameters, request bodies, and headers natively.

Stricter Editing Mode

To prevent accidental data loss, ApiBanker enforces a Stricter Editing Mode on destructive operations.

Attempting to delete a request, collection, or environment will prompt a highly visible confirmation dialog. Additionally, undo/redo buffers are securely segregated per tab to ensure actions in one request do not affect another.
