How to Contribute

Join the Community

We welcome contributions from everyone. Whether you are fixing bugs, improving documentation, or proposing new features, your help is appreciated!

Getting Started

  • Fork the repository on GitHub.
  • Create a new branch for your feature or bugfix (e.g. feature/amazing-feature).
  • Ensure you follow the Stricter Editing mode paradigms implemented in the core UI.
  • Run tests locally to ensure no regressions.
  • Submit a Pull Request targeting the main branch.

Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.

Reporting Issues

If you encounter bugs, open an issue on our GitHub tracker. Be sure to include:

  • Your OS and Environment details.
  • Steps to reproduce the error.
  • Relevant logs from the built-in console.

💙 Support ApiBanker Development

ApiBanker is free to use. If this tool has been valuable to your workflow, consider supporting its continued development with a voluntary contribution.

Your support directly helps fund ongoing feature development, bug fixes, and documentation improvements.
