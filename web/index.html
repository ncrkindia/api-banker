Powerful Scripting

Write advanced Pre-request and Test scripts using modern JavaScript. Validate JSON responses, extract dynamic tokens into environment variables, and chain complex workflows together effortlessly.

  • ✅ Rhino Engine: ES6 compatible syntax
  • ✅ Built-in Assertions: pm.expect() out of the box
  • ✅ Dynamic State: Seamlessly mutate global variables
Pre-request Tests 

// Validate Status Code
pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});

// Parse and Extract Token
const jsonData = pm.response.json();
pm.test("Token is present", function () {
    pm.expect(jsonData.access_token).to.be.a("string");
});

pm.environment.set("auth_token", jsonData.access_token);
