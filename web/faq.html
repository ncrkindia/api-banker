Frequently Asked Questions

Is ApiBanker free to use?
Yes, ApiBanker is a proprietary software but is completely free to use.
What platforms are supported?
We provide native executables and installers for Windows, macOS, and Linux.
Does it support syncing between devices?
Workspaces are saved locally as JSON files. You can easily sync them via Git or any cloud storage drive.
How does the Stricter Editing Mode work?
It acts as a safeguard. Any destructive operation (like deleting a request or a collection) requires explicit confirmation to prevent data loss.
