Setup & GitHub

⚠️ Important Notice

Building ApiBanker locally from source is only required if you intend to contribute to the codebase. For standard usage, please download the pre-compiled binaries from the Download page.

Prerequisites

To build and run ApiBanker from source, you will need the following tools installed on your system:

  • Java Development Kit (JDK) 21 (or higher).
    Note: If you intend to build the Standalone Native Executable, you MUST install GraalVM JDK 21+.
  • Apache Maven (for building from source).
  • WiX Toolset v3 (Required ONLY for Windows users building the .msi native installer via jpackage).
  • C++ Build Tools (Required ONLY for building the .exe via GraalVM Native Image).
    • Windows: Visual Studio C++ Build Tools.
    • Linux: gcc and glibc-devel.
    • macOS: Xcode Command Line Tools.

Building & Packaging Options

ApiBanker supports three different distribution formats. We provide automated build scripts (build.bat for Windows and build.sh for Linux/macOS) to handle the entire lifecycle.

1. Quick Build (Recommended)

The build scripts perform a complete two-phase build: generating the JAR/ZIP bundle, followed by the platform-native installer.


# Windows
:: Full build: JAR + ZIP + .msi installer
build.bat

# Linux / macOS
chmod +x build.sh
./build.sh

2. Professional Native Installers (MSI/PKG/DEB)

Builds a complete standalone setup wizard bundled with a custom, stripped-down JRE via jpackage.


# Using build script
build.bat --native       # Windows
./build.sh --native      # Linux / macOS

# Manual Maven
mvn clean package -P native-installer-windows

3. Standalone Native Executable (GraalVM AOT)

Compiles the Java bytecode directly to native machine code for lightning-fast startup times with zero external dependencies.


# Using build script
build.bat --graal        # Windows
./build.sh --graal       # Linux / macOS

Running Locally during Development

To instantly launch the application directly from your IDE or terminal without packaging:


mvn compile exec:java -Dexec.mainClass="in.slpro.apibanker.App"

Alternatively, run the compiled JAR directly after packaging:


java -jar target/apibanker-2.0.0.jar
